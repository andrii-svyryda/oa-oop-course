# Лабораторна робота 12. Узагальнений зв’язаний список

| | |
|---|---|
| **План** | Індивідуальний план |
| **Номер** | 12 |
| **Лекція** | [Узагальнення](../../lectures/02-generics.md) |
| **Поняття** | узагальнення, IEnumerable |

## Завдання

Реалізуйте користувацький зв’язаний список.

## Вимоги

- `foreach`, узагальнення (generic).
- Методи: `AddFirst`, `AddLast`, `Clear`, `Contains`, `Find`, `FindLast`, `Remove`, `RemoveFirst`, `RemoveLast`.

## Примітки

У загальному та індивідуальному планах номери робіт можуть не збігатися. У загальному плані це лабораторна №7.
