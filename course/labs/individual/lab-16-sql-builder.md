## Завдання

Реалізуйте клас `SqlBuilder` для вибірки з сортуванням, PostgreSQL і MS SQL.

## Вимоги

- Fluent API на кшталт `Select<User>().OrderBy(...).Take(10)`.
- https://maxtoroq.github.io/DbExtensions/docs/SqlBuilder.html
