# Лабораторна робота 17. Узагальнений медіатор

| | |
|---|---|
| **План** | Індивідуальний план |
| **Номер** | 17 |
| **Лекція** | [Поведінкові патерни](../../lectures/08-gof-behavioral.md) |
| **Поняття** | Mediator, DI |

## Завдання

Реалізуйте узагальнений медіатор за спрощеним інтерфейсом MediatR, юніт-тести маршрутизації, окремий проєкт.

## Вимоги

- Не використовуйте готову бібліотеку як реалізацію.
- `IMediator` / `ISender` / `IPublisher` / `IRequestHandler<,>` — transient.
- https://github.com/jbogard/MediatR

## Примітки

У загальному та індивідуальному планах номери робіт можуть не збігатися. У загальному плані це лабораторна №14.
