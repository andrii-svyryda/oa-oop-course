Observer / оглядач

Один-до-багатьох: зміна суб’єкта → усі підписники Update.

interface IObserver {
  void Update(Product product);
}
interface ISubject {
  void RegisterObserver(IObserver o);
  void RemoveObserver(IObserver o);
  void NotifyObservers(Product p);
}

Де живе в .NET

  • event — класичний спостерігач мови
  • IObservable<T> / Rx
  • Типовий чат: новий користувач → нотифікації (можна вимкнути)

Команда

Запит як об’єкт: можна ставити в чергу, скасовувати, логувати.

  • Invoker знає лише ICommand.Execute()
  • Конкретна команда тримає receiver і параметри
  • Близько до MediatR: IRequest / IRequestHandler

Стратегія

Сімейство алгоритмів за спільним інтерфейсом. Об’єкт-контекст делегує роботу стратегії.

  • Фільтри повідомлень у чаті
  • Напрямок сортування через делегат — спрощена стратегія
  • Знижки з лекції SOLID — теж стратегія

Mediator

Об’єкти не знають одне про одного — говорять через посередника.

  • +
  • менше зв’язності, централізована логіка взаємодії
  • −
  • ризик «бог-об’єкта», зайва непрямість
