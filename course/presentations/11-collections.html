Колекції в C#

Яку структуру обрати — питання інваріантів доступу, а не «що перше згадали».

List<T>

Типізований список з доступом за індексом, динамічний розмір.

List<string> dirs = new(Directory.EnumerateDirectories(docPath));
foreach (var dir in dirs) Console.WriteLine(Path.GetFileName(dir));

Dictionary і хеш-функція

  • Ключ → значення, ключі унікальні
  • Пошук через hash code
  • Колізії: кілька ключів у одному кошику
  • Equals + GetHashCode мають бути узгоджені
static int HashFunction(string s, string[] array) {
  int total = 0;
  foreach (char c in s) total += c;
  return total % array.Length;
}

HashSet vs SortedSet

HashSet — унікальні елементи, порядок не гарантований, швидкі union / intersect / except.

SortedSet — унікальні й одразу впорядковані за зростанням. Дорожча вставка, дешевший «відсортований перегляд».

Stack і Queue

Stack — LIFO (undo, DFS).

Queue — FIFO (черга задач, BFS, Hangfire як ідея фонових jobs).

stack.Push(x); var y = stack.Pop();
queue.Enqueue(x); var z = queue.Dequeue();
