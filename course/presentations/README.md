# Презентації лекцій

Тут ви знайдете самостійні HTML-слайди до кожної лекції. Щоб переглянути їх, просто відкрийте файл [index.html](index.html) у вашому браузері (це доступно без інтернету та додаткового налаштування).

## Як керувати презентацією

| Клавіша / дія | Що робить |
|---|---|
| ← →, пробіл, PageUp/PageDown | Навігація |
| Home / End | Перший / останній слайд |
| O або Esc | Огляд усіх слайдів |
| F | Повний екран |
| Клік ліворуч / праворуч | Попередній / наступний |
| Ctrl+P | Друк або збереження в PDF |
