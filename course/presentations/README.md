# Презентації лекцій

Тут знаходяться самостійні HTML-слайди до кожної лекції. Щоб переглянути їх, просто відкрийте [index.html](index.html) у браузері (доступно без інтернету та додаткового налаштування).

## Як керувати презентацією

| Клавіша / дія | Що робить |
|---|---|
| ← →, пробіл, PageUp/PageDown | Навігація |
| Home / End | Перший / останній слайд |
| O або Esc | Огляд усіх слайдів |
| F | Повний екран |
| Клік ліворуч / праворуч | Попередній / наступний |
| Ctrl+P | Друк або PDF |
