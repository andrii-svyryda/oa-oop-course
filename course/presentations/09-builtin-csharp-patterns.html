Що вже є в BCL

Ви вже користуєтесь цими патернами, можливо, не знаючи їхніх назв.

Singleton

Замість самописних блокувань використовуйте Lazy<T> — це готове thread-safe відкладене створення об’єкта.

Observer

Звичайні event або інтерфейс IObservable<T> — це класичний спостерігач. Хтось публікує, інші підписуються.

Builder

Знайомий вам StringBuilder або fluent-налаштування HTTP-клієнта — це все будівельники, які крок за кроком збирають результат.

Ще три впізнавані шаблони

Prototype

Інтерфейс ICloneable та метод MemberwiseClone дозволяють клонувати об’єкти. Але пам’ятайте: це поверхневе копіювання (shallow copy).

Iterator

Коли ви пишете foreach, повертаєте IEnumerable або використовуєте yield — ви працюєте з ітератором.

Factory

Метод Activator.CreateInstance вміє створювати об’єкти за іменем типу — чим не фабрика?

Lazy<T> як одинак

Ось як просто тепер виглядає Singleton. Ніяких lock, усе робить сам фреймворк.

public sealed class AppConfig {
  private static readonly Lazy<AppConfig> _lazy =
    new(() => new AppConfig());
  public static AppConfig Instance => _lazy.Value;
  private AppConfig() { /* завантажуємо конфіг лише раз */ }
}

Прототип і копіювання

Якщо вам треба зробити копію об’єкта, реалізуйте ICloneable.

class Car : ICloneable {
  private int width;
  public object Clone() => new Car(this.width);
}
Car two = (Car)carOne.Clone();
// Зверніть увагу: MemberwiseClone копіює лише посилання, а не весь граф об’єктів.

IObservable — спостерігач у бібліотеці

Сучасний підхід до подій — це реактивні потоки даних.

var range = Observable.Range(10, 15);
range.Subscribe(Console.WriteLine, () => Console.WriteLine("Completed"));

var fromEnum = new List<string> { "a", "b", "c" }.ToObservable();
fromEnum.Subscribe(Console.WriteLine);

Питання для самоперевірки

Чи можете пояснити своїми словами те, що вже було в курсі?

  • Стовпи ООП, різницю між virtual / override / overload, для чого потрібен sealed, як працює upcast та downcast.
  • Що таке boxing і constraints (ми розбирали це на лекції 02). Не плутайте їх з implicit operator.
  • Принципи SOLID своїми словами та навіщо нам потрібен IoC.

Повний список питань до інтерв’ю ви знайдете в лабораторній 15. Covariance і reflection також є там, ми не виносимо їх в окремі лекції.
