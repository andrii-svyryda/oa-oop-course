Ще три впізнавані шаблони

Prototype

ICloneable + MemberwiseClone (shallow!).

Iterator

IEnumerable / foreach / yield.

Factory

Activator.CreateInstance за іменем типу.

Lazy<T> як одинак

public sealed class AppConfig {
  private static readonly Lazy<AppConfig> _lazy =
    new(() => new AppConfig());
  public static AppConfig Instance => _lazy.Value;
  private AppConfig() { /* load once */ }
}

Прототип і копіювання

class Car : ICloneable {
  private int width;
  public object Clone() => new Car(this.width);
}
Car two = (Car)carOne.Clone();
// MemberwiseClone копіює посилання, не графи

IObservable — спостерігач у бібліотеці

var range = Observable.Range(10, 15);
range.Subscribe(Console.WriteLine, () => Console.WriteLine("Completed"));

var fromEnum = new List<string> { "a", "b", "c" }.ToObservable();
fromEnum.Subscribe(Console.WriteLine);

Питання для самоперевірки

  • Стовпи ООП, virtual / override / overload, sealed, boxing
  • Generics constraints, covariance, reflection, IDisposable
  • SOLID на пальцях + навіщо IoC
