# Курс «OOP on top of C#»

Тут зібрані навчальні матеріали курсу з об’єктноорієнтованого програмування (C# / .NET). Читайте їх як підручник: слайди дадуть вам коротку вижимку, конспект — розгорнуте пояснення, а код допоможе побачити результати наживо.

## З чого почати

1. Відкрийте [презентації](presentations/index.html) у браузері (клавіші ← →, пробіл, O — огляд, F — повний екран).
2. Поруч тримайте конспект з [lectures/README.md](lectures/README.md).
3. Запустіть проєкт лекції з [code/README.md](../code/README.md).
4. Лабораторні виконуйте лише зі свого плану — номери в загальному та індивідуальному планах не збігаються.

## Структура

```
course/
  lectures/            # конспекти лекцій
  presentations/       # HTML-слайди
  post-presentations/  # додаткові нотатки після лекції 01
  labs/
    general/           # лабораторні загального плану
    individual/        # лабораторні індивідуального плану
    assets/            # ілюстрації до завдань
code/                  # консольні приклади до лекцій 01–12
```

- Лекції: [lectures/README.md](lectures/README.md)
- Презентації: [presentations/index.html](presentations/index.html)
- Як керувати слайдами: [presentations/README.md](presentations/README.md)
- Додаткові нотатки: [post-presentations/README.md](post-presentations/README.md)
- Лабораторні (загальний план): [labs/general/README.md](labs/general/README.md)
- Лабораторні (індивідуальний план): [labs/individual/README.md](labs/individual/README.md)
- Код: [../code/README.md](../code/README.md)

## Два плани

Перелік лекцій для всіх однаковий. А от **набір і номери лабораторних робіт** відрізняються. В індивідуальному плані ви детальніше проходите раннє ООП (окремі роботи на інтерфейси та default interface methods). Тому завжди дивіться README саме свого плану, а не сусіда.

## Оцінка

- **61 бал** — ви отримаєте за лабораторні роботи з вашого плану.
- **39 балів** — виділено на екзамен: запитання з курсу та невелике практичне завдання, яке ви виконаєте наживо.

Деталі ви знайдете у [вступній лекції](lectures/00-intro.md).

## Практичні вправи всередині лекцій

Окрім нумерованих лабораторних, у [теорії ООП](lectures/01-oop-theory.md) є вправи (наприклад, розширювальні методи для `int`). В індивідуальному плані інтерфейси рахунків і default interface methods винесені в окремі лабораторні роботи.
