# Курс «OOP on top of C#»

Тут зібрані всі структуровані матеріали курсу з об’єктноорієнтованого програмування (C# / .NET), які знадобляться вам для навчання.

## Структура

```
course/
  lectures/          # конспекти лекцій
  presentations/     # HTML-презентації (слайди) до кожної лекції
  labs/
    general/         # лабораторні роботи загального плану
    individual/      # лабораторні роботи індивідуального плану
    assets/          # ілюстрації до завдань
```

- Лекції: [lectures/README.md](lectures/README.md)
- Презентації (HTML): [presentations/index.html](presentations/index.html)
- Лабораторні (загальний план): [labs/general/README.md](labs/general/README.md)
- Лабораторні (індивідуальний план): [labs/individual/README.md](labs/individual/README.md)

## Як працювати з планами

Перелік лекцій є однаковим, незалежно від вашого плану. Однак **порядок і набір лабораторних робіт** відрізняється: якщо ви навчаєтеся за індивідуальним планом, ви детальніше розглядатимете ранні теми ООП (виконаєте окремі роботи на інтерфейси та default interface methods), а нумерація наступних робіт відповідно зміститься.

## Практичні завдання всередині лекцій

Зверніть увагу: окрім нумерованих лабораторних робіт, у [теорії ООП](lectures/01-oop-theory.md) є додаткові практичні вправи. Вони не винесені окремим файлом у загальному плані, проте ми радимо виконати їх для кращого розуміння:

- розширювальні методи для `int`;
- в індивідуальному плані інтерфейси рахунків і default interface methods винесені як окремі лабораторні роботи.
