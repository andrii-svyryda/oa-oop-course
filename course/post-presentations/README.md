# Пост-презентації

Додаткові матеріали до лекцій, які показують **на наступному занятті** — те, що не встигли або пропустили під час основної презентації.

Це **не** HTML-слайди. Тут лише markdown-конспекти для викладача та студентів. Основні презентації в [presentations/](../presentations/) не змінюються.

## Як користуватися

1. Проведіть основну лекцію за [HTML-презентацією](../presentations/index.html) і [конспектом](../lectures/README.md).
2. На наступному занятті (або на початку наступної теми) відкрийте відповідний файл з цієї папки.
3. За потреби доповнюйте конспект у `.md` — HTML-версії для пост-презентацій не передбачено.
