# Додаткові нотатки після лекцій

Тут лежить матеріал, який ви можете дочитати **після** основної лекції. Зверніть увагу, що це не окремі HTML-слайди й не заміна конспекту.

Зараз тут є нотатки лише до лекції 01 — ми розглянемо модифікатори доступу та те, що не вмістилося на слайди.

## Як користуватися

1. Спочатку пройдіть основну лекцію за [презентацією](../presentations/index.html) і [конспектом](../lectures/README.md).
2. Якщо хочете зануритися глибше — відкрийте файл із цієї папки.
3. Код до слайдів шукайте у відповідних проєктах `code/lecture-NN-...`.
