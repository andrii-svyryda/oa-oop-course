## Орієнтири для заняття

Цю тему в навчальному плані залишено відкритою. Рекомендований мінімум для лекції або семінару:

1. **Кортежі (`tuple`, `ValueTuple`)** — як альтернатива одноразовим DTO.
2. **`implicit` / `explicit` operator** — перетворення між своїми типами без втрати інкапсуляції. Це не boxing: boxing — value type ↔ `object` (лекція 02). Тут ви самі задаєте правило.
3. **`record` / `record struct`** — незмінні моделі та value-based equality.
4. **Pattern matching** — як доповнення до поліморфізму, а не його заміна.
5. **Default interface methods** — уже були в лекції 01 і в лабораторних індивідуального плану (меню рахунків). Сьогодні лише нагадування: це синтаксис, не заміна стратегії / DI.

Джерела з вступу курсу: [документація Microsoft](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals) та *Pro C# 10 with .NET 6*.
