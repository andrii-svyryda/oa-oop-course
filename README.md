# OOP on top of C#

Вітаю вас на курсі об’єктноорієнтованого програмування (C# / .NET). Усі матеріали зібрані так, щоб ви могли навчатися самостійно: до кожної лекції є слайди, розгорнутий конспект і код.

## З чого почати

1. Прочитайте, [як влаштований курс](course/README.md).
2. Відкрийте [презентації](course/presentations/index.html) у браузері.
3. Читайте конспект тієї самої лекції з [course/lectures](course/lectures/README.md).
4. Запускайте приклади з [code/README.md](code/README.md).
5. Лабораторні виконуйте лише зі свого плану:
   - [загальний план](course/labs/general/README.md)
   - [індивідуальний план](course/labs/individual/README.md)

Вам знадобиться встановлений [.NET 8 SDK](https://dotnet.microsoft.com/download).
